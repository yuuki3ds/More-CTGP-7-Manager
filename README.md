# More！CTGP-7 Manager
CTGP-7にキャラクターをたくさん追加したい！
でも動作は軽くしたい！
そんな方向けのアプリです。
Charactersフォルダを分割し簡単に切り替えが可能

# More！CTGP-7ユーザーの場合
パック内Characters1/2/3を切り替えます。

# 一般ユーザーの場合
独自のCharactersフォルダを切り替えます。
アプリで読み込む形へのフォルダ管理は自動ですが、.chpackファイルの仕分けは手動で行ってください

# その他機能
アプリ内から直接CTGP-7を起動可能。
アプリのアップデートはアプリ内で可能。
手動更新や更新のチェックも可能
豊富な設定画面、ユーザーインターフェース、秘密のExtraメニューもあります。
